# CibusUNISA
Sito web per il progetto di TSW 2025-2026 classe resto 0 

Questo sito web nasce dall'idea di un locale strategico situato nel cuore del campus di Fisciano, un posizionamento identitario che si riflette direttamente nel nome del progetto. CibusUNISA unisce infatti il legame indissolubile con l'Università degli Studi di Salerno all'essenza stessa del servizio offerto: un "cibus" di qualità pensato su misura per la comunità studentesca.

La piattaforma risponde a un'esigenza concreta e quotidiana all'interno della vita universitaria: conciliare la necessità di un'alimentazione sana con ritmi di studio serrati. Troppo spesso la fretta costringe a compromessi sulla qualità del cibo, trasformando il tempo nel peggior nemico dello studente. 

CibusUNISA inverte questa dinamica. Grazie a un modello ottimizzato che garantisce una preparazione rapida e una consegna immediata dal momento dell'ordine, la freschezza degli ingredienti e il benessere alimentare si integrano perfettamente con le scadenze accademiche. In questo modo, l'efficienza del servizio trasforma il tempo da ostacolo a principale alleato della giornata universitaria.
